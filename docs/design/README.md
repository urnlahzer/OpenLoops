# Design references

Two files exported from the Claude Design project for the desktop window redesign (September 2026):

- `OpenLoops UI Spec.dc.html` — the build specification: tokens, window frame, Review and Sources screens, states, accessibility, non-goals.
- `OpenLoops Companion.dc.html` — the interactive reference rendering with invented sample data.

Both files reference a `support.js` runtime from the design tool that is not part of this repository; open them for their markup, styles, and copy. The implementation plan is `docs/plans/2026-09-09-fluent-ui-redesign.md`.
